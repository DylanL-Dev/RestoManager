# RestoManager furniture collection

Original transparent raster assets created with the built-in imagegen tool for this project.

Art direction: realistic restaurant simulation furniture, warm oak, emerald or beige upholstery, brass, a consistent near-overhead camera and soft upper-left lighting. No text, numbers, people, floor or room are baked into the sprites. The application supplies table labels and reservation states separately.

Generation prompt template:

> Production game sprite for RestoManager restaurant floor-plan editor. Create ONE isolated asset: [subject]. Premium realistic 3D game furniture, warm oak, emerald velvet, brass, natural detailed materials. Camera near top-down orthographic, looking down at 75 degrees above ground, front of furniture towards bottom of image. Show subtle visible thickness and legs, same camera and soft upper-left lighting across the collection. Center whole object within square canvas with 8 percent clear padding, no cropped parts. Genuine transparent alpha background, no floor plane, no room, no lettering, no numbers, no UI, no people. Gentle tight contact shadow only, asset suitable to overlay on a wooden floor. Beautiful believable luxury hotel restaurant furniture, realistic rendering, not vector drawing.

Subjects: square tables with 2 and 4 emerald chairs; round tables with 2 and 4 beige chairs; rectangular tables with 6 and 10 emerald chairs; facing banquettes around an oak table; bar with four stools; monstera in terracotta pot; brass floor lamp; plaster wall; open oak door; double window; stone pillar; stainless steel kitchen island; pair of porcelain toilets; standalone upholstered chair; buffet sideboard; host desk; lounge sofa.

WebP versions retain transparency and are compressed for mobile use. Original table capacity and geometry remain in the floor-plan model. Unsupported seating counts use the existing vector renderer so the image never implies a different seat count. Sprites have a fixed material palette; the vector renderer retains fully custom colours. Rotation turns the fixed view with the object; this is not an interactive 3D camera.
